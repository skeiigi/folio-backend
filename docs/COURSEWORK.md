# Соответствие ПР02–ПР04

| Требование предыдущих работ | Реализация |
| --- | --- |
| US01 найти работу по формату и стилю | `GET /artworks`, фильтры в каталоге |
| US02 рассмотреть 3D со всех сторон | `GLB` хранится как MediaFile, React-клиент включает интерактивный просмотр |
| US03 понять специализацию, услуги, цену и срок | CreatorProfile и Service в `GET /creators/:id` |
| US05 отправить автору бриф | `POST /briefs`, роль заказчика, id автора, бюджет, срок, закрытые референсы |
| US06 опубликовать работу | Draft → upload cover/model/preview → publish; сервер проверяет необходимые файлы |
| US07 отредактировать профиль и услуги | `PATCH /creators/:id`, CRUD услуг, ограниченный `layoutConfig` |

Персона заказчика Антон представлена демо-аккаунтом и экраном поиска, профиля автора, формы брифа и списка заявок. Персона автора Мира представлена демо-аккаунтом, мастерской, редакторами профиля, работ и услуг, а также входящими брифами. В матрице доступа ПР03 гость читает лишь опубликованное; заказчик управляет собственными брифами; автор управляет своим профилем, работами, услугами и входящими заявками; администратор модерирует пользователей и публикации.

Точки преобразования данных в сценарии «отправка брифа»: фронтенд валидирует ввод; API повторно валидирует и получает `clientUserId` из токена; транзакция создаёт `briefs`, событие `brief_events` и, если настроена внешняя доставка, запись `event_outbox`; ответ содержит новый UUID и статус `submitted`. Референс загружается отдельным запросом, проверяется по содержимому и сохраняется как `media_files` + `storage_objects`; ошибка загрузки не удаляет созданный бриф. При активном Resend worker доставляет письмо после транзакции, поэтому временная ошибка почты не отменяет заявку. Этот механизм соответствует схеме потока данных из ПР03.

Для отчёта ПР04: можно использовать локальные скриншоты из `docs/screenshots` репозитория интерфейса и таблицу полей/экранов в его `docs/COURSEWORK.md`. Реальное время разработки нужно указать по собственным записям пользователя; репозиторий его не выдумывает.
